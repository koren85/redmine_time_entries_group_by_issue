# Фильтр по родительским задачам - Инструкция по использованию

## Описание

Добавлен новый фильтр "Родительская задача" (Parent issue) для отчетов по трудозатратам в Redmine. Этот фильтр позволяет отфильтровать трудозатраты по задачам на основе их родительских задач.

## Возможности фильтра

Фильтр поддерживает следующие операторы:

1. **Содержит (=)** - показывает трудозатраты по задачам, у которых родитель имеет указанные ID
   - Пример: `parent_issue_id = 100,200` покажет трудозатраты по всем подзадачам задач #100 и #200

2. **Не содержит (!=)** - исключает трудозатраты по задачам с указанными родителями
   - Пример: `parent_issue_id != 100` исключит трудозатраты по подзадачам задачи #100

3. **Есть родитель (\*)** - показывает только трудозатраты по подзадачам (задачам, у которых есть родитель)

4. **Нет родителя (!\*)** - показывает только трудозатраты по задачам верхнего уровня (без родителя)

## Как использовать в Redmine

### Через веб-интерфейс:

1. Перейдите в раздел "Трудозатраты" (Time Entries) проекта или в глобальные трудозатраты
2. Нажмите "Добавить фильтр" (Add filter)
3. Выберите "Родительская задача" (Parent issue) из списка доступных фильтров
4. Выберите нужный оператор:
   - "содержит" (~) или "равно" (=) - для фильтрации по конкретным родителям
   - "не содержит" (!~) или "не равно" (!) - для исключения конкретных родителей
   - "есть" (*) - для показа только подзадач
   - "нет" (!*) - для показа только задач верхнего уровня
   - "начинается с" (^) - для фильтрации по началу номера родителя
   - "заканчивается на" ($) - для фильтрации по концу номера родителя
5. **В текстовое поле введите номера родительских задач** (для операторов с вводом):
   - Можно вводить через запятую: `100, 200, 300`
   - Можно через пробелы: `100 200 300`
   - Можно без пробелов: `100,200,300`
6. Примените фильтр

### Примеры использования:

**Пример 1: Найти все трудозатраты по подзадачам задачи #340**
- Фильтр: Родительская задача
- Оператор: содержит
- Значение: 340

**Пример 2: Показать трудозатраты только по задачам верхнего уровня**
- Фильтр: Родительская задача
- Оператор: нет

**Пример 3: Исключить трудозатраты по подзадачам задач #100 и #200**
- Фильтр: Родительская задача
- Оператор: не содержит
- Значения: 100,200

## Совместимость с группировкой

Фильтр полностью совместим с функциями группировки плагина:

- Можно одновременно фильтровать по родительским задачам и группировать по задачам
- Можно фильтровать по родительским задачам и группировать по родительским задачам
- Все существующие функции группировки продолжают работать корректно

## Техническая информация

### SQL запросы, генерируемые фильтром:

- **Оператор "="**: `time_entries.issue_id IN (SELECT id FROM issues WHERE parent_id IN (...))`
- **Оператор "!="**: `time_entries.issue_id NOT IN (SELECT id FROM issues WHERE parent_id IN (...))`
- **Оператор "\*"**: `time_entries.issue_id IN (SELECT id FROM issues WHERE parent_id IS NOT NULL)`
- **Оператор "!\*"**: `(time_entries.issue_id IS NULL OR time_entries.issue_id IN (SELECT id FROM issues WHERE parent_id IS NULL))`

## Важные замечания

1. Фильтр показывает трудозатраты **только по дочерним задачам**, НЕ включая трудозатраты самих родительских задач
2. При вводе несуществующих ID родительских задач результат будет пустым
3. Фильтр работает только с прямыми потомками (не рекурсивно по всей иерархии)
